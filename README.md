# Mindtrix

Mindtrix es un catálogo de guías digitales en español. Los rubros incluyen Robótica, Jardinería, Mecánica, Carpintería, Prompts de IA, Ciencia y Arte.

La colección Taller Curioso reúne **Robótica Casera** y **Ciencia y arte en casa**. Los PDF completos se reservan para la entrega a compradores.
